# v0.1.0 发布验收

验证日期：2026-11-12。公开版本来自独立源码目录，未复用作者的任务数据库、个人知识库或项目索引。

## 已验证

- macOS / Python 3.9.6 / Node 24.22.1：全量128项隔离测试通过，无跳过；覆盖任务依赖与恢复、长输入输出、检索与来源边界、梦记忆复核与反馈、配置、实例隔离、安装和发布扫描。
- 干净临时源码启动：一个原创示例项目、六篇示例知识、零历史任务；状态和六篇知识正文HTTP读取通过。
- 正常浏览器入口：七个导航页、知识查询、来源片段、任务创建表单和默认角色跟随主执行器可用；390px视口与弹窗没有横向溢出。
- 真实Codex：合成清单任务完成，产物落盘、6/6检查及独立审查通过；后台自动提炼一条经验并经独立复核启用。第二任务实际召回、传入并引用该经验，审查通过，重复梦整理返回零新增；18个HTTP产物SHA-256全部一致。输入和验证对象均为合成示例。
- Harness固定版本实际安装，隔离配置下的版本、headless帮助及原生子进程启动通过；没有在安装测试中调用模型。
- Autoloop固定提交实际安装，独立数据目录和端口启动、worker在线、停止及上游协议解析通过。它未作为核心启动的必需依赖。
- 启动器在端口属于其他实例时拒绝接管，停止时核对进程身份。
- 发布文件逐份选择，暂存区密钥/路径/运行状态扫描及人工内容复核通过；Three.js文件哈希与来源清单一致。

## 验证边界

- 远端 macOS / Linux、Python 3.9 / 3.12 测试状态以仓库 Actions 为准。真实模型调用在macOS验证，不代表所有操作系统与账号组合均已验证。
- WorkBuddy适配器和长输入输出通过隔离测试；本次公开版发布未重复验证新的WorkBuddy账号真实任务。Grok和豆包提供人工回填，未宣称自动API接入。
- 词面检索可能漏掉同义语句。经验通过复核不等于业务效果已证实；任务样例和模拟反馈都不能替代用户实际使用反馈。
- WSL2、Windows原生、多人权限、公网部署和长期无人值守不在本版验收范围。
- 公开文件中没有作者的私有运行证据；原始验收日志留在作者本地，避免误传本机路径、模型状态或账号信息。
